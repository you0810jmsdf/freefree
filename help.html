千葉ニュータウン地域掲示板 - 使い方ガイド

掲示板トップ  |  事業主マイページ

このサイトは千葉ニュータウン周辺（印西市・白井市・船橋市北部など）の事業者・団体の皆さまが、地域向けに告知ポスターを無料で掲載できる掲示板です。閲覧にはログインは不要です。

1. 掲示板の見方

トップページではカテゴリ（飲食、医療、教育、イベントなど）やエリア別にポスターを絞り込んで閲覧できます。

  • ポスター画像をタップすると詳細（事業主情報・連絡先・PR文）が表示されます。
  • 各ポスターには常設イベントのバッジが付きます。
  • 電話・LINE・ウェブサイトなど、事業主が公開した連絡手段から直接お問い合わせできます。

2. 事業主・団体登録の流れ

  1. ヘッダー右上の「事業主ログイン/マイページ」をタップ
  2. Googleアカウントでログイン（初回のみ認可が必要）
  3. 「新規登録」フォームを開く
  4. 事業主区分（事業主 / 団体）を選択
  5. 屋号・団体名、代表者名、連絡先、エリア、代表カテゴリ、PR文などを入力
  6. 登録完了後、マイページからポスターを投稿できます
登録は無料です。メールアドレスはログインに使うGoogleアカウントのアドレスが自動的に使用されます。

3. 「事業主」と「団体」の違い

区分常設ポスターイベント告知想定利用者
事業主 最大3件まで 無制限 飲食店・医療機関・学習塾・サロン・小売店などの営業中の事業者
団体 投稿不可 無制限 自治会・サークル・NPO・ボランティア団体などの非営利活動
団体区分はイベント告知専用です。常設の店舗紹介を掲載したい場合は、事業主区分で登録してください。

4. ポスターの投稿・編集

投稿する

  1. マイページの「新規ポスター投稿」を開く
  2. ポスター種別（常設 / イベント）を選択
  3. タイトル、個別カテゴリ（空欄なら代表カテゴリを使用）、掲載開始日・終了日を入力
  4. ポスター画像（A4縦推奨・JPEG/PNG）をアップロード
  5. ひとことコメント（任意）を入れて保存

編集・終了

  • マイページのポスター一覧から編集ボタンで再編集できます。
  • 掲載を終了する場合は終了ボタンを押してください（画像は残ります）。
  • 掲載期間外のポスターは自動的に非公開になります。
個別カテゴリを指定すると代表カテゴリより優先されます。イベントごとにカテゴリを変えたい場合に便利です。

5. 掲載ルール

  • 常設ポスターは1事業主あたり最大3件まで投稿できます。
  • イベント告知は件数制限なく投稿できますが、掲載期間を必ず指定してください。
  • 公序良俗に反する内容、事実と異なる誇大広告、政治・宗教の勧誘、マルチ商法などは掲載できません。
  • 著作権・肖像権を侵害しない画像のみアップロードしてください。
  • 運営側で不適切と判断したポスターは、予告なく非公開にする場合があります。
